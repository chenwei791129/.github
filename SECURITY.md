# Security Policy

This policy applies to every repository under
[github.com/chenwei791129](https://github.com/chenwei791129) that does not ship
its own `SECURITY.md`.

## Supported versions

Only the latest release of each project receives security fixes. Container
images are rebuilt from the latest tag; older image tags are not patched.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the **Security** tab
of the affected repository and choose **Report a vulnerability**. The report is
visible only to the maintainer until a fix is published.

Include, where possible:

- the affected repository, version or image tag
- steps to reproduce or a proof of concept
- the impact you believe the issue has

You can expect an acknowledgement within 7 days. Fixes are published as a new
release with a GitHub Security Advisory when the issue is confirmed.
